# ESP32-S3 蓝牙(BLE)控制 —— 手机控制开关灯 + 学号上报

## 一、这个工程做了什么

对照实践要求：

| 要求 | 实现方式 |
|------|----------|
| PC 或手机发 ON / OFF 控制开发板开关灯 | 手机蓝牙连上后，向 RX 特征写入 `ON` / `OFF`，板载 RGB 灯亮/灭 |
| 开发板按键按下，PC 或手机上显示学号 | 按下板上 **BOOT** 键，ESP32 通过蓝牙把 `STUDENT_ID=8524035254` 推给手机 |
| 进阶（可选） | 本次未做。如需可在此基础上接巴法云 MQTT（见文末「后续扩展」） |

**工程里有两套等价代码，用哪个都行：**

| 目录 | 用途 | 说明 |
|------|------|------|
| `esp32s3_ble/` | **Arduino IDE**（当前主推） | 标准 sketch 布局，双击 `.ino` 即可打开 |
| `src/` + `include/` + `platformio.ini` | PlatformIO | 备用。两处代码内容一致，改了记得两边同步 |

## 二、先看这两个坑（很重要）

### 坑 1：ESP32-S3 没有"经典蓝牙串口"

HC-05 那类模块用的是**经典蓝牙 SPP**，手机装个"蓝牙串口助手"配对就能用。
**ESP32-S3 只支持 BLE（低功耗蓝牙），不支持经典蓝牙。**

所以手机端不能用"配对 → 直接收发"的方式，必须用 **BLE 调试类 APP**，通过标准的
**Nordic UART Service (NUS)** 来收发字符串。APP 操作步骤见第五节，照着点就行。

### 坑 2：板载 RGB 灯要用专用驱动，不能用 digitalWrite

板载那颗灯是 **WS2812 单总线彩灯**，不是普通 LED。它靠一根线传时序数据，
**用 `digitalWrite()` 或普通 PWM 点不亮**，必须用专用驱动。

本工程直接用 Arduino-ESP32 核心自带的 `rgbLedWrite()`，**不需要装任何第三方库**。
引脚也不写死，用核心的 `RGB_BUILTIN` 宏（ESP32-S3 上即 **GPIO48**）——
这一点已和参考工程 `ESP32S3_Serial_StudentID` 对齐，对方在真机上验证过。

**怎么确认灯是好的**：烧录后板子会自己 **红 → 绿 → 蓝 各闪一次**。
- 看到闪烁 → 驱动正常
- 完全不闪 → 见第八节排错

> 补充：网上有资料说 v1.1 版把灯挪到了 GPIO38。`RGB_BUILTIN` 宏会跟着核心的
> 板级定义走；万一你的板子灯不亮，把 `config.h` 里兜底那两行的
> `#define RGB_BUILTIN 48` 取消注释并改成 `38` 即可。

## 三、用 Arduino IDE 编译烧录（主推）

### 1. 装 Arduino IDE

官网 <https://www.arduino.cc/en/software> 下载 **Arduino IDE 2.x**，装好即可。

### 2. 配置开发板管理器网址（关键，决定下载快不快）

打开 **文件 → 首选项**，在「**附加开发板管理器网址**」里填入：

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

> 这个源指向 GitHub，经实测本机可达 **约 850 KB/s**。
> 别用默认的那个 espressif 官方源，实测只有 30 多 KB/s，慢 20 多倍。

### 3. 安装 ESP32 开发板支持

**工具 → 开发板 → 开发板管理器** → 搜索 `esp32` →
找到 **esp32 by Espressif Systems** → 选版本 **3.3.9** → 安装。

> 会下载工具链，总共几百 MB，耐心等几分钟。
> 参考工程用的就是这个 3.3.9，保持版本一致最稳。

### 4. 打开工程

**文件 → 打开** → 选择
`E:\claude\esp32s3-ble\esp32s3_ble\esp32s3_ble.ino`

> 注意要进到 `esp32s3_ble` 这一层，打开里面的 `.ino`；
> 直接打开上层目录 Arduino IDE 会报找不到 sketch。

### 5. 选择开发板和参数

**工具 → 开发板 → esp32 → ESP32S3 Dev Module**

然后按下面的表逐项设好（**这几项设错是最常见的失败原因**）：

| 菜单项 | 设成 | 为什么 |
|--------|------|--------|
| **USB CDC On Boot** | **Enabled** | 让串口输出走板上 USB 口（参考工程也是这么设的） |
| **Flash Size** | **8MB (64Mb)** | 你的板子是 ESP32-S3-WROOM-1U **N8R2**，Flash 是 8MB |
| **PSRAM** | **Disabled** | 本工程用不到 PSRAM，关掉最省事 |
| **Partition Scheme** | **Default 8MB with spiffs** | 固件很小，默认分区足够 |
| **Upload Speed** | 921600 | 烧录速度 |
| **CPU Frequency** | 240MHz | 默认即可 |
| **Flash Mode** | QIO 80MHz | 默认即可 |

> **串口监视器看不到输出？** 把 **USB CDC On Boot** 在 Enabled / Disabled 之间换一下。
> 板子有两个 Type-C 口：插标着 **UART** 的口用 Disabled，插标着 **USB** 的口用 Enabled。
> 哪个有输出就用哪个，不用纠结原理。

### 6. 烧录

1. 用 USB 线连上开发板
2. **工具 → 端口** 选对应的 COM 口（认不出就拔插一次看哪个新出现）
3. 点 **→**（上传）按钮

> 卡在 `Connecting...` 不动：**按住 BOOT 键 → 点一下 RST 键 → 松开 BOOT**，
> 让板子进入下载模式，再点上传。

### 7. 打开串口监视器

点右上角放大镜图标，波特率选 **115200**。正常会看到：

```
========== ESP32-S3 蓝牙控制 ==========
学号     : 8524035254
蓝牙名   : ESP32S3-8524035254
RGB 灯脚 : GPIO48 （核心 RGB_BUILTIN 宏）
[LED] 自检：红-绿-蓝各闪一次……
[BLE] 已开始广播，设备名: ESP32S3-8524035254
```

## 五、手机端调试步骤（nRF Connect）

### 装 APP

| 平台 | 推荐 APP |
|------|---------|
| Android / iOS | **nRF Connect for Mobile**（Nordic 官方，免费，最好用） |
| Android 备选 | BLE 调试助手、蓝牙调试器（选支持"NUS / Nordic UART"的） |
| iOS 备选 | LightBlue |

**不要**用连 HC-05 的那种"蓝牙串口助手"，S3 搜不到。

### 连接与操作

1. 板子上电，串口打印 `[BLE] 已开始广播，设备名: ESP32S3-8524035254`
2. 打开 nRF Connect → 点 **SCAN** → 找到 **`ESP32S3-8524035254`** → 点 **CONNECT**
   - 名字带学号，方便在教室一堆设备里认出自己的板子
3. 连接后展开名为 **`Unknown Service`**（UUID `6E400001-...`）的服务，里面有两条特征：

   | 特征 | UUID 后缀 | 作用 |
   |------|-----------|------|
   | **RX** | `...0002` | 你往这里**写**命令 |
   | **TX** | `...0003` | ESP32 往这里**发**消息 |

4. **先订阅 TX**（关键一步，不做就收不到学号）：
   在 TX 特征那一行，点最右边的 **三个箭头图标 ↓↑↓**，状态变成 *Notifications enabled*
5. **测试开灯**：在 **RX** 特征那一行点 **向上箭头 ↑** → 选 `ASCII` 方式 → 输入 `ON` → **SEND**
   - 板载 RGB 灯变**绿色**，同时 TX 那行出现 `OK LED=ON`
6. **测试关灯**：同样写入 `OFF` → 灯灭，TX 显示 `OK LED=OFF`
7. **测试学号上报**：按下板上 **BOOT** 键 → TX 那行出现 **`STUDENT_ID=8524035254`**
   - 串口也会同时打印 `[KEY] BOOT 键按下 -> 上报学号 8524035254`

> 补充：TX 特征带 READ 属性，所以即使忘了开通知，也可以点 TX 那一行的读取图标
> 直接"读"到学号。作为兜底手段。

## 六、支持的命令

在手机 APP 里往 **RX** 特征写入（ASCII 文本，大小写都行）：

| 命令 | 效果 | 回传 |
|------|------|------|
| `ON` | 点亮板载 RGB 灯（绿色） | `OK LED=ON` |
| `OFF` | 熄灭板载 RGB 灯 | `OK LED=OFF` |
| `ID` | 查询学号（不用按键也能查） | `STUDENT_ID=8524035254` |

其它内容会回 `ERR 可用命令: ON / OFF / ID`。

## 七、答辩演示流程（建议顺序）

1. **上电**：板子红绿蓝各闪一次 → 说明程序在跑，顺便证明灯驱动正常
2. **手机连蓝牙**：nRF Connect 扫描到 `ESP32S3-8524035254` 并连接 → 展示设备名里带学号
3. **手机发 ON**：灯亮起 → 对应「手机发 ON 控制开发板开关灯」
4. **手机发 OFF**：灯熄灭 → 对应「发 OFF」
5. **按下开发板 BOOT 键**：手机 TX 处出现学号 → 对应「开发板按键按下，手机显示学号」
6. 串口监视器全程开着，展示日志，说明程序状态可观测

> 基本要求里的「PC 机」同样满足：Windows 上装 **nRF Connect for Desktop**
> 走同一套 NUS 特征就能操作，步骤与手机一致。

## 八、代码结构

```
esp32s3-ble/
├── esp32s3_ble/            ★ Arduino IDE 用这个目录
│   ├── esp32s3_ble.ino     主程序：启动流程 + 按键消抖 + 主循环
│   ├── config.h            ★ 所有需要改的东西都在这里
│   ├── led_ctrl.h / .cpp   板载 WS2812 灯驱动（红绿蓝自检）
│   └── ble_uart.h / .cpp   蓝牙 NUS 服务（收命令、发通知）
│
├── src/ + include/         PlatformIO 版（代码内容与上面一致）
├── platformio.ini          PlatformIO 工程配置
└── README.md               本文件
```

**改学号**：只改 `config.h` 里的 `STUDENT_ID` 一处，
蓝牙设备名会自动跟着变（`BLE_DEVICE_NAME` 是拼接出来的）。

## 九、常见问题

**Q：Arduino IDE 里找不到 `BLEDevice.h`？**
A：说明 ESP32 开发板支持没装好。回到第三节第 3 步，确认 **esp32 by Espressif Systems**
装上了，且开发板选的是 **ESP32S3 Dev Module**。本工程用核心自带的 BLE 库，不用额外装。

**Q：编译报 `rgbLedWrite` was not declared？**
A：核心版本太老。`rgbLedWrite()` 需要 core 2.0.5 以上，建议直接装 3.3.9。

**Q：手机搜不到设备？**
- 确认串口打印了「已开始广播」
- 确认手机蓝牙已打开，且 APP 里点的是 SCAN 而不是"已配对设备"
- 板子刚断开过连接时会重新广播，稍等几秒再扫

**Q：手机连上了，发 ON 没反应？**
- 确认写的是 **RX**（`...0002`）特征，不是 TX
- 确认写入的内容是纯 ASCII 文本 `ON`，没有多余的换行或引号

**Q：按键按了，手机没收到学号？**
- 必须先**订阅 TX 特征的通知**（第五节第 4 步），BLE 从机不能推给没订阅的手机
- 或者改用「读 TX 特征」的方式兜底

**Q：灯一直不亮？**
- 先看串口有没有打印「自检：红-绿-蓝各闪一次」，有打印但灯不亮 → 引脚问题，
  按坑 2 末尾的说明把 `RGB_BUILTIN` 兜底值改成 `38` 重烧
- 自检那三次闪烁要盯着看，每次 250ms，很快

**Q：烧录报错 / 串口占用？**
- 关掉串口监视器再烧；或按第三节第 6 步的 BOOT+RST 进下载模式
